# KiloCode provider coverage — generated reference

**Status:** generated catalog evidence, not a routing policy.

`data/kilocode_provider_coverage.json` contains the detailed provider/model snapshot generated by `scripts/build_kilocode_provider_coverage.py`.

The snapshot can inform provider capability discovery, but it does not authorize Stagewarden to select a provider, model, account, paid route, or fallback. In v3 every node receives provider/model policy from user configuration or an explicitly approved policy.

Generated data must expose:

- provider and exact model identifiers;
- source and capture timestamp;
- context/input/output limits when known;
- auth/capability metadata without secrets;
- freshness/staleness;
- distinction between official model IDs and local aliases/routes.

The Node Knowledge Store may index this data in the `provider` namespace. It must not mix provider metadata with node evidence or treat a catalog row as runtime usage.

## Validation

```bash
python3 scripts/build_kilocode_provider_coverage.py --help
```
